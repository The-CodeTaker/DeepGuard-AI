# DeepGuard AI - Machine Learning

This directory contains the machine learning components of DeepGuard AI.

## Planned capabilities

- Image deepfake detection
- Video deepfake detection
- Audio deepfake detection
- Explainable AI
- Manipulated-region localization
- Model evaluation
- Inference pipeline

## Structure

- `src/data` - Dataset loading and preprocessing
- `src/models` - Model architectures
- `src/training` - Training pipelines
- `src/inference` - Model inference
- `src/explainability` - Grad-CAM and attention visualization
- `src/utils` - Shared utilities
- `tests` - ML tests
